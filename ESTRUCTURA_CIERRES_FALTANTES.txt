===============================================================================
FLUJO DE EJECUCIÓN:
===============================================================================

PASO 1: IDENTIFICAR FALTANTES
┌──────────────────────────────────────────────────────────────┐
│ python process_missing_cierres.py                            │
├──────────────────────────────────────────────────────────────┤
│ 1. Lee geocom.totals (enero 2026)      → 300 cierres        │
│ 2. Lee DW.cierres (enero 2026)          → 127 cierres        │
│ 3. Compara por localid + pos + closed   → 173 FALTANTES      │
└──────────────────────────────────────────────────────────────┘

PASO 2: EJECUTAR QA
┌──────────────────────────────────────────────────────────────┐
│ Para cada cierre faltante:                                   │
├──────────────────────────────────────────────────────────────┤
│ ✓ ¿Existe en geocom.totals?                                  │
│ ✓ ¿Hay datos de ventas en geocom?                            │
│ ✓ ¿Hay datos de medios de pago en geocom?                    │
│ ✓ ¿NO existe en DW.cierres?       (validación de faltante)   │
│ ✓ ¿NO existe en DW.cierres_detalle?                          │
└──────────────────────────────────────────────────────────────┘
Salida: qa_missing_cierres.csv

PASO 3: GENERAR COMANDOS
┌──────────────────────────────────────────────────────────────┐
│ Para cada cierre faltante:                                   │
├──────────────────────────────────────────────────────────────┤
│ python run.py --modulos VENTAS MEDIOS_PAGO ANULACIONES \     │
│   --localid 1 --pos 1 --fecha_ini 20260105 --fecha_fin 20... │
└──────────────────────────────────────────────────────────────┘
Salida: missing_cierres_commands.sh

PASO 4: EJECUTAR EN PROD (CUANDO SEA APROBADO)
┌──────────────────────────────────────────────────────────────┐
│ bash missing_cierres_commands.sh                             │
│                                                              │
│ (Esto cargará los 173 cierres en DW)                         │
└──────────────────────────────────────────────────────────────┘

===============================================================================
VALIDACIONES DE QA (Deben pasar TODAS antes de ir a PROD):
===============================================================================

Test 1: Cierre existe en geocom
   └─ Verifica que el registro esté en totals

Test 2: Datos de ventas existen en geocom
   └─ Verifica que haya tickets/ventas para ese cierre

Test 3: Datos de medios pago existen en geocom
   └─ Verifica que haya pagos registrados

Test 4: Cierre NO existe en DW (CRÍTICO)
   └─ Confirma que realmente falta en DW

Test 5: Detalle NO existe en DW (CRÍTICO)
   └─ Confirma que no hay datos parciales en DW

CASOS DE ERROR:
===============================================================================

Si Test FAIL: "Cierre NO existe en DW"
   └─ El cierre ya fue cargado → NO procesar

Si Test FAIL: "Datos de ventas existen en geocom"
   └─ Cierre sin ventas → Revisar si es válido

Si Test ERROR: "Error al conectar geocom"
   └─ Verificar credenciales en .env

Si generó 0 cierres faltantes:
   └─ Todos los cierres ya fueron cargados ✓
